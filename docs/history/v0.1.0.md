> [!IMPORTANT]
> **Back up `/data`.** This is Rainy's first release. The data folder holds the
> database and `secret.key`, which encrypts stored passwords; back up both
> together before every upgrade. Future releases migrate the database
> automatically on startup. If managers will edit tags or rename files, back up
> your music as well.

> [!NOTE]
> Install with the production `docker-compose.yml` and a `.env` file, then run
> `docker compose up -d --pull always`. Set `RAINY_IMAGE` to pin this release
> instead of following `latest`.

Rainy v0.1.0 is the first public release: a self-hosted music server for NAS
devices with a Subsonic API, an installable web player, and library management
built in.

## Playback And The Web Player

- Stream MP3, FLAC, AAC/M4A/ALAC, Ogg Vorbis, Opus, WAV, AIFF, APE, WavPack,
  WMA, DSD, and more, with seeking on original files and on-the-fly
  transcoding to MP3, Opus, or AAC through ffmpeg.
- Play from an iOS-style interface: a floating mini player on phones, a
  full-screen Now Playing sheet with artwork-colored backgrounds, synced
  lyrics, a draggable queue, shuffle and repeat, and a desktop player bar with
  side panels.
- Control playback from lock screens, headsets, and media keys through Media
  Session, use AirPlay on iOS, and use keyboard shortcuts on desktop.
- Choose streaming quality, conversion format, ReplayGain normalization, and
  next-song preloading per device.
- Install the web app as a PWA on iOS, Android, and desktop.
- Resume the play queue across the web app and Subsonic clients.
- Listen to internet radio stations added by an administrator.

## Library Browsing And Search

- Browse home, albums, artists, songs, genres, favorites, and playlists, with
  pinyin indexing for Chinese artist names and article-aware sorting.
- Search across artists, albums, and songs regardless of case, accents, and
  full-width characters.
- Star and rate tracks, albums, and artists; build personal and public
  playlists.
- Scan on startup, on a schedule, or on demand; detect moved files without
  losing favorites or play counts; and skip hidden, NAS system, and
  `.rainyignore` folders.
- Repair GBK, Big5, and Shift-JIS mojibake when reading tags, without
  modifying files.

## Library Management

- Edit tags for one track or many, with "multiple values" handling, raw tag
  access, and preview-before-apply tools: auto-number, tags from file name,
  find and replace, change case, copy field, and clear field.
- Embed covers or save folder images, and edit embedded or `.lrc` lyrics with
  a line-stamping helper.
- Rename and organize files by pattern with a conflict-aware preview.
- Upload files and folders, optionally organized by tags.
- Delete to a restorable trash, find problems with the library doctor, rewrite
  garbled tags as UTF-8, browse folders, and review every change in the edit
  history.

## Subsonic Clients

- Implement the Subsonic API 1.16.1 with the OpenSubsonic `formPost`,
  `songLyrics`, `transcodeOffset`, `apiKeyAuthentication`, and
  `indexBasedQueue` extensions.
- Support password, token, and API-key authentication, with per-user API keys
  managed in Settings.
- Support full-library sync through empty `search3` queries for clients such
  as Symfonium.

## Accounts And Security

- Create the first administrator on first visit; manage users with
  administrator, manager, and download permissions.
- Use HttpOnly session cookies with sliding expiry, rate-limited sign-in, and
  hashed session tokens and API keys.
- Confine every file operation to the library roots and record it in the edit
  history.

## Operations

- Ship one Docker image for `linux/amd64` and `linux/arm64` on Docker Hub
  (`yexca/rainy`) and the GitHub Container Registry.
- Configure the production Compose stack through `.env`: image, music and data
  paths, host port, `PUID`/`PGID`/`UMASK`, time zone, scan schedule, log level,
  proxy trust, and session lifetime.
- Run as an unprivileged user after fixing data-folder ownership, with clear
  startup messages for permission problems and read-only music mounts.
- Reset passwords and list users with the `rainy user` command.
